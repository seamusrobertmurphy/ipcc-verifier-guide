# 02.inputs manifest

Nothing under this folder is committed except this manifest, other markdown notes and the small derived files under `derived/`. The `.gitignore` excludes `02.inputs/**` and re-admits `*.md` and `derived/**`.

Every dataset the book reads is given one row here before any code reads it. The row names the dataset, the path under `02.inputs/`, the link it was retrieved from, the DOI as a resolvable https link where one exists, the retrieval date and the licence. The comment above each line of code that reads a dataset copies its name and link from this table.
